## Tips khi crop

1. Crop vùng vừa đủ, chừa lề trắng 5-10px
2. Resolution ~150 DPI là đủ
3. Save PNG (không JPG)
4. Tên file viết HOA `.PNG`
5. Multi-passage a/b/c: passage xuất hiện trước trong PDF = a, kế tiếp = b, cuối = c
